# RelayDesk · 接力台

> 让多个 AI 编程工具像接力赛一样合作。一个停下，下一个带着交接单接着跑；每一棒都有快照，可以复核，也可以退回。

2026 年 9 月开始开发，源码私有，面试可现场演示。

## 解决什么问题

用 Claude Code、Codex、DeepSeek 等工具写代码时，常见三种中断：额度用完、模型卡住、结果需要另一个模型检查。直接换工具会丢掉上下文，前一个模型说「做完了」也无从核实。接力台把一次开发拆成一棒一棒，每一棒都留下交接单和文件快照。

## 核心功能

| 功能 | 做法 |
| --- | --- |
| 自动接力 | 按顺序派给成员；额度用完、超时或报错自动换下一位，可设最多几棒 |
| 换模型继续 | 读取本项目的 Claude Code / Codex 本地会话：Claude 沿 `parentUuid` 还原主分支，Codex 兼容新旧格式并去重；预览后带着上下文交给另一位成员 |
| 强弱分工 | 强模型拆成小步，弱模型逐步执行，强模型复核；复核没过可退回到任意一棒的快照 |
| 群聊与投票 | 讨论、对比（互相看不到）、匿名投票（一个 AI 一票，不能投自己）；投完由强模型当主席汇总，采纳后写进任务约定，之后每一棒都遵守 |
| 验收 | 清单全部打勾后可请强模型终审；「声称完成」和「实际完成」分开记录 |

## 设计亮点

- **不信任项目里的内容**：检查命令只在本机用户确认过才运行（按项目记命令哈希，改了就要重新确认）；`.relay/` 里出现符号链接整个项目停用，`AGENTS.md` 这类规矩文件只写到项目内部
- **密钥不落盘、不出网**：配置只存环境变量名；发给模型的材料先抹掉疑似密钥
- **会话读取有边界**：只按实际工作目录列出会话，接口用不透明 ID，不接收任意日志路径；预览不启动模型、不改原会话
- **快照独立于用户 git**：快照存在 `.relay/snapshots` 的独立仓库，不污染用户的提交历史

## 技术实现

| 部分 | 实现 |
| --- | --- |
| 核心与服务 | TypeScript、Node.js，命令行 `relay` + 本地 HTTP 服务 |
| 网页 | 原生 JavaScript + CSS，中英双语、深色模式、窄屏适配 |
| 成员接入 | Claude Code、Codex、DeepSeek Harness 等命令行工具，以及 OpenAI 兼容接口 |
| 测试 | Node 内置测试框架，191 项；假的 `claude` / `codex` / `dsh` 程序与假模型接口 |

规模：源码约 1.4 万行 TypeScript、1.1 万行网页代码，测试约 5800 行。

## 怎么验证的

- 191 项自动化测试全部通过，覆盖接入、快照、调度、换人、复核、退回、群聊投票、网页接口
- 安全修补都做过变异检查：逐处去掉防护，对应测试必定失败
- 浏览器实测会话接续、项目切换、深色界面和 390 像素窄屏

自动化测试用模拟的成员程序验证调度和解析；模型实际干活的质量，另外在真实工具上验收。
